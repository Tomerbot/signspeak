# תסריט לסרטון הדמו (2 דקות)

הסרטון מראה את האפליקציה **האמיתית** עובדת, עם היד שלך. בלי לדבר: את הכתוביות (ואם תרצה גם
קול באנגלית) Claude מוסיף אחר כך.

## לפני שמקליטים

- [ ] **תאורה טובה**: אור מלפנים (חלון או מנורה מולך), לא מאחוריך.
- [ ] **רקע רגוע**: קיר חלק מאחוריך עדיף.
- [ ] **המצלמה רואה את הפנים ואת החזה** (צריך את החזה ל-Please ו-Sorry). שב קצת רחוק מהמחשב.
- [ ] **פרטיות**: שום דבר עם השם המלא, בית הספר או הכתובת שלך לא נראה במצלמה או על המסך
      (חולצה עם שם בית ספר, תעודות על הקיר, לשוניות בדפדפן). אמא בודקת לפני שמפרסמים.
- [ ] פותחים את האפליקציה ב-Edge: `python -m http.server 8000` ואז <http://localhost:8000>
      (או הקישור של GitHub Pages, אם כבר העלית).
- [ ] **מתרגלים קודם** כל סימן שתראה בסרטון, עד שהוא עובד בקלות. אפשר לשנות את הסדר לפי מה
      שעובד הכי טוב.
- [ ] מאפסים את ההתקדמות: About ← Reset practice progress.
- [ ] מגדילים את חלון הדפדפן למסך מלא.

## איך מקליטים

**Win + Alt + R** פותח/עוצר הקלטה של החלון (Xbox Game Bar). הוא מקליט גם את הקול של המחשב, אז
רואים ושומעים את האפליקציה אומרת את המילים. הסרטון נשמר ב: `סרטונים ← לכידות` (Videos\Captures).

- לעשות כל סימן **לאט וברור**, ולחכות שנייה אחרי שהמילה מופיעה.
- טעות? לא נורא. ממשיכים. Claude חותך את הטעויות.
- אפשר להקליט כמה קטעים קצרים במקום קטע אחד ארוך.

השופטים נותנים 30% על איך שזה בנוי, אז זה עוזר. 5 שניות מספיקות.
