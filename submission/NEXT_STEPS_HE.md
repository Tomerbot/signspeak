# מה נשאר לעשות עד ההגשה

⏰ **הדדליין: יום שלישי, 6 באוקטובר 2026, בשעה 07:00 בבוקר שעון ישראל.**
(בחוקים כתוב 5 באוקטובר 21:00 שעון קליפורניה. ב-Devpost כתוב 23:45, אבל עדיף ללכת לפי המוקדם.)
בפועל: **להגיש עד יום שני, 5 באוקטובר, בערב.** בשלישי בבוקר יש בית ספר, ואי אפשר לסמוך על הבוקר.

## 1. עם אמא: לבדוק שמותר להשתתף
- [ ] לשלוח את המייל מ-`EMAIL_ORGANIZERS.md` (החוקים אומרים "תיכון ומכללה", ואתה בן 13).
- [ ] Devpost: נרשמים ומצטרפים להאקתון (Join hackathon), עם אמא.
- [ ] אם המארגנים עונים שאסור, עוצרים ולא מגישים. אפשר להשתמש בפרויקט בהאקתון אחר.

## 2. להריץ ולבדוק את האפליקציה (לבד)
- [ ] פותחים טרמינל בתיקייה `projects\signspeak` ומריצים:
      `python -m http.server 8000`
- [ ] פותחים ב-Edge את <http://localhost:8000> ולוחצים **Turn on camera** (ומאשרים מצלמה).
- [ ] עוברים על **כל 10 הסימנים** במצב Practice. לכל סימן כותבים לעצמך: עובד / עובד קשה / לא עובד.
- [ ] סימן שלא עובד? פותחים <http://localhost:8000/?debug>, עושים את הסימן, **מצלמים מסך** ושולחים
      לי עם שם הסימן. אני אכוון את המספרים.
- [ ] בודקים שהקול עובד (Say each sign out loud).

## 3. GitHub (עם אמא)
- [ ] ב-GitHub יוצרים מאגר **ציבורי** בשם `signspeak`, **בלי** README ובלי License (יש כבר).
- [ ] תגיד לי "תעשה commit", ואני אכין את הקוד להעלאה.
- [ ] `git push -u origin main` (ההתחברות נפתחת לבד בדפדפן).
- [ ] Settings ← Pages ← Deploy from a branch ← `main` / root ← Save.
- [ ] אחרי דקה-שתיים בודקים שהאפליקציה עובדת ב: `https://tomerbot.github.io/signspeak/`

## 4. סרטון
- [ ] מקליטים לפי `DEMO_SCRIPT.md` (Win + Alt + R), בלי לדבר.
- [ ] שמים את הקובץ ב-Downloads ואומרים לי. אני עורך: חיתוכים, כתוביות, ואם תרצה קול באנגלית.
- [ ] **אמא בודקת** את הסרטון (שאין שם מלא, בית ספר או כתובת).
- [ ] יוטיוב: **Unlisted**, "No, it's not made for kids", ומעתיקים קישור מהסוג `watch?v=`.

## 5. הגשה ב-Devpost (עם אמא)
- [ ] ב-`DEVPOST.md`: כותבים את הפסקה של **Inspiration** במילים שלך (סיפור אמיתי), ומשנים כל
      משפט שלא נשמע כמוך.
- [ ] Project name, Tagline ← מ-`DEVPOST.md`.
- [ ] About the project ← מדביקים את כל הטקסט מ-`DEVPOST.md` (מ-Inspiration עד What's next).
- [ ] Built with ← התגיות מ-`DEVPOST.md`.
- [ ] Try it out ← קישור ל-GitHub וקישור ל-GitHub Pages.
- [ ] Video ← הקישור מיוטיוב.
- [ ] Image gallery ← `SignSpeak_thumbnail.png` (בתיקיית Downloads) ועוד 2–3 צילומי מסך מהסרטון.
- [ ] Team ← רק השם הפרטי שלך.
- [ ] שדות שלא קשורים אליך ← משאירים ריקים.
- [ ] **Submit** לפני יום שני בערב. אחרי ההגשה אפשר עדיין לתקן עד הדדליין.

- לא משלמים לאף אחד כדי להשתתף או לקבל פרס. הפרסים כאן הם קרדיטים ותעודה, והם מגיעים דרך אמא.
